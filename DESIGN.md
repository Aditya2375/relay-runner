# Relay Runner: control surface

Status: staged for owner review after independent review passed. Not published.

## Product truth

The repository is a Node.js teaching prototype with four signed, allowlisted transport tasks, a single-edit proposal mode, and a separate multi-step coding loop. The coding loop can execute approved shell commands when explicitly enabled. It is not an OS sandbox. The web terminal is a browser port using WebCrypto and an in-tab fixture workspace, not a connection to the installed CLI or a live model.

## Direction

A precision control surface, not another green serif product template. Oversized neutral grotesk, warm graphite, oxidized orange, fine engraved rules, a custom projected request-routing instrument. The interactive object demonstrates a real signature check. The typography and object carry the page; no decorative feature-card wall, invented adoption figures, fake customer logos, or background gradients.

## Interaction

The handoff instrument has four experiments: valid request, changed signature, expired request and replay. Results use the browser port's actual HMAC checks and dispatch, not random status text. The terminal remains a separate hands-on workspace, with fixture notes stored locally and an explicit reset control. Motion has a pause control, freezes frame output, respects reduced motion, and stops when the page is hidden or the canvas is outside the viewport.

Setup is a compact, OS-aware guide with copyable commands, progressive disclosure for optional model setup, and explicit data/cost boundaries. Existing shell recordings are labelled as recordings on Linux, not native Windows/macOS footage. Security distinguishes transport from coding-agent command access.
