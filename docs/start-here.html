This website is not a connection to your computer. Relay Runner runs in your terminal. The web playground uses separate demo files.

01 / GET THE CODE

Choose your system.

The commands below need Node.js 20+ and Git. The ZIP alternative does not need Git. There are no runtime packages to install.

Windows

Open PowerShell. Check your installed Node version:

node -v

Use a currently supported Node release, version 20 or newer. Download Node from nodejs.org if needed. Then clone the repository with Git:

git clone https://github.com/Aditya2375/relay-runner.git
cd relay-runner
npm run demo

No Git? Open the repository, choose Code, then Download ZIP. Unzip it, open a terminal inside that folder and run npm run demo.

02 / CHECK THE BOUNDARY

Watch a refusal, too.

The local demo creates a temporary home, signs four jobs and dispatches them. A command job is refused before command access is explicitly enabled. That refusal is expected, not a broken install.

npm test

The test suite runs without model credentials. It checks the transport, path guards, approval flows and provider request handling with test doubles. Passing tests is not a security certification.

03 / OPTIONAL

Bring a model.

Skip this section if you only want signed local tasks. Model modes need an endpoint you can use. Provider pricing, quotas and available models depend on your account. Check them before sending a request.

Hosted providers receive project content and your task. Common secret files are excluded, but the filter is not a secret detector. Use a small, non-private test project first. A local endpoint keeps inference on your machine only if you configured it to run locally.

Gemini

Create your own key at Google AI Studio. Set it in the same terminal you will use for Relay Runner.

PowerShell:

$env:RELAY_GEMINI_KEY="YOUR_KEY_HERE"

macOS / Linux:

export RELAY_GEMINI_KEY="YOUR_KEY_HERE"

Replace the placeholder privately. Shell history may retain the command; follow your shell's guidance for protecting secrets. Do not paste keys into chat, screenshots or source control.

Anthropic or OpenAI-compatible endpoints

Use RELAY_ANTHROPIC_KEY with --provider anthropic, or RELAY_OPENAI_KEY with --provider openai. Set RELAY_OPENAI_BASE_URL for another compatible endpoint and RELAY_OPENAI_MODEL for a model it serves. Use a model your account can access.

For a local Ollama endpoint, set RELAY_OPENAI_BASE_URL=http://localhost:11434/v1 and the model name you installed. The local Ollama path does not require a key. Relay Runner does not install a model or start Ollama for you.

Ask for one edit.

node bin/relay.js ai --task "Add a short summary to README.md" --workspace . --provider gemini

The program reads the workspace, asks your provider for edits, shows a diff and asks Apply these edits? [y/N]. Press Enter to decline. Only type y after reading the changes. This example points at the current folder; change --workspace to your intended test project.

Environment variables apply to the terminal where you set them. Model requests may incur provider charges. Logs in .relay/ai.log can contain task and project details.

04 / WHEN YOU NEED MORE

A loop, not a blank cheque.

node bin/relay.js agent --task "Review this project and propose a small improvement" --workspace .

Agent mode can read and propose writes over multiple steps. Writes require approval. It stops at a step cap, 12 by default. Whole-file changes, model errors and early exits are real limitations.

Commands are off in the example above. Adding --enable-commands permits approved shell execution. Those shell commands are not sandboxed and can affect your computer beyond the workspace. The file-path guard does not contain a shell.

You may approve an action type for the rest of a run with a. That is a wider permission than approving one action. Read the prompt before choosing.

IF SOMETHING STOPS

Read the failure.

Node or npm is not recognised

Check that Node is installed and available on PATH. Close and reopen the terminal after installing. Run node -v and confirm version 20 or newer.

Missing module or package.json

Check your current folder. It should contain package.json, bin, src and test. Use cd to move into the cloned or unzipped project before running npm commands.

Provider error, invalid model or rate limit

Confirm that the selected provider, key and model belong together. Check the provider's error and account limits. Do not repeatedly retry a paid request blindly. Relay Runner does not automatically retry provider calls.

The model proposes a command and the loop stops

Command mode is off unless enabled at startup. That refusal is intentional. Review the task and exact proposed command before deciding whether shell access is necessary.
