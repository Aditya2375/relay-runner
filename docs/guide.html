Relay Runner is a Node.js 20+ project without runtime dependencies. Download or clone its repository, then run the mock agent and local runner together.

Get it running

Requires Node.js 20 or newer. There are no runtime dependencies, so npm install fetches nothing.

git clone https://github.com/Aditya2375/relay-runner.git
cd relay-runner
npm install
npm run demo
npm test

The demo creates temporary state, signs four jobs and executes the named tasks. The first command job is rejected, then a fresh one runs with explicit operator opt-in. No network service or AI subscription is required.

Use the CLI

node bin/relay.js init --home ./sandbox
node bin/relay.js issue system.summary --home ./sandbox --out ./sandbox/summary.json
node bin/relay.js run ./sandbox/summary.json --home ./sandbox

issue signs an instruction to a file using the shared local key in ./sandbox/.relay/secret. The runner verifies the HMAC signature, two-minute window and one-time ID before dispatching it.

Real transport, on localhost

node bin/relay.js allow my-agent --home ./sandbox
node bin/relay.js listen --home ./sandbox
node bin/relay-agent.js system.summary --sender my-agent \
  --key-file ./sandbox/.relay/senders/my-agent.key

The listener binds 127.0.0.1 only. Each sender gets its own key; unknown senders, bad signatures, stale jobs and replays are rejected. Command mode still needs the operator's --enable-commands. Every request and decision is logged to .relay/run.log.

AI mode, with your own key

export RELAY_GEMINI_KEY=your-own-free-key
node bin/relay.js ai --task "describe the change" --workspace . --provider gemini

AI mode reads the project, asks the AI provider for edits, shows a diff and writes only after you approve. Three providers are supported with --provider: gemini (RELAY_GEMINI_KEY, the free path via aistudio.google.com), anthropic (RELAY_ANTHROPIC_KEY, pay-per-token - there is no free tier) and openai (RELAY_OPENAI_KEY plus optional RELAY_OPENAI_BASE_URL, covering OpenAI, OpenRouter and local Ollama, which is free and needs no key). No key is stored in the repo. Files you point it at are sent to that provider's API, and every run is logged to .relay/ai.log with the provider and model. New to all of this? Start here for the beginner walkthrough.

What can it run?

  • system.summary: platform and Node version.
  • workspace.list: up to 50 top-level names, not contents.
  • notes.append: append up to 500 characters to a fixed private file.
  • command.node-version: a fixed node --version template, only when the operator supplies --enable-commands.

Not a sandbox. Any process that can read the shared key can impersonate the signing agent. Do not connect this teaching prototype to untrusted remote jobs. There is no arbitrary shell execution, even with the command flag.

See the repository README for the full threat model, protocol shape and source code. The GitHub Pages site is a static companion to the repository, not a connection to your runner.
